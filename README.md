# Проект: Movie Library (Личная кинотека)
**Автор:** Елфимова Мария
**Дата создания:** Мой 2026

## Описание программы
«Личная кинотека» — это настольное приложение на Python с графическим интерфейсом (GUI), предназначенное для удобного хранения и систематизации информации о ваших любимых фильмах. Программа позволяет вести локальную базу данных фильмов без использования сложных СУБД.

## Возможности программы
* **Добавление данных:** сохранение названия, жанра, года выпуска и рейтинга фильма.
* **Просмотр:** отображение всей библиотеки в виде удобной таблицы.
* **Фильтрация:** быстрый поиск фильмов по жанру или году выпуска.
* **Хранение данных:** автоматическое сохранение и загрузка данных из файла `movies.json`.

## Проверка корректности ввода (Валидация)
Программа защищена от ошибок пользователя:
* Поля «Название» и «Жанр» обязательны для заполнения.
* Поле **«Год»** принимает только целые числа.
* Поле **«Рейтинг»** проверяет ввод дробных чисел в диапазоне от **0 до 10**.
* При некорректном вводе программа выводит окно с предупреждением.

## Требования
* Python версии 3.x.
* Библиотека `tkinter` (обычно поставляется вместе с Python).

## Установка и запуск
1. Склонируйте репозиторий или скачайте файлы `main.py`, `.gitignore` и `README.md`.
2. Убедитесь, что у вас установлен Python.
3. Запустите программу через терминал или командную строку:
   ```bash
   python main.py
   ```

## Примеры использования
1. **Добавление:** Введите "Начало", "Фантастика", "2010", "8.8" и нажмите «Добавить фильм». Запись появится в таблице.
2. **Фильтрация:** Введите в поле фильтра "Комедия", чтобы увидеть только фильмы этого жанра.
3. **Сохранение:** Просто закройте программу — все данные уже сохранены в `movies.json` и будут доступны при следующем запуске.
